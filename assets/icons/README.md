# Replaceable SVG icon pack

All UI icons live in this folder. Replace an icon by uploading a new SVG with the **same filename**; no need to edit JavaScript or HTML for the listed icon assets. Keep a `viewBox` (recommended `0 0 24 24`) and use `currentColor` for stroke/fill where the icon should adapt to the theme.

## Icon filename map

| File | Intended use |
|---|---|
| `plus.svg` | Add a class or item |
| `minus.svg` | Remove/collapse control |
| `edit.svg` | Edit a class |
| `more-horizontal.svg` | More actions menu |
| `save.svg` | Save |
| `share.svg` | Share |
| `download.svg` | Download JSON backup |
| `eye.svg` | Preview for screenshots |
| `file-pdf.svg` | PDF / print |
| `calendar.svg` | Timetable / dates |
| `clock.svg` | Time |
| `book.svg` | Subjects |
| `user.svg` | Teacher |
| `map-pin.svg` | Room/location |
| `check.svg` | Confirm |
| `chevron-down.svg` | Dropdown |
| `mail.svg` | Email contact |
| `instagram.svg` | Instagram contact |
| `reddit.svg` | Reddit contact |
| `settings.svg` | Settings |
| `close.svg` | Close dialog |

Social SVGs are generic placeholders. Replace them with your preferred properly licensed assets using the same filenames.
