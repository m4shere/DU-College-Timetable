# Quick editing notes

- Add subjects and teachers in **Subjects & teachers** first. You can store several teachers under one subject.
- Use **Quick add** to schedule the subject in a chosen day/time. Select several teachers for co-taught labs. Long classes can occupy up to four consecutive slots.
- The little pencil on a scheduled class opens its class form. Plus buttons pre-fill the relevant day/time.
- Theme selector lives in the header. It updates palette-colored classes right away. Subject color overrides and individual class color overrides stay custom.
- **Save backup** downloads the editable `.json` data; **Save PDF** prints the timetable; **Preview** creates a clean screenshot surface.
- The timing setup only controls start time, period length and count. The class start dropdown is generated automatically from these values.
- Your browser's existing `duCollegeTimetableBuilder.v2` data is read and normalized; back it up before updating the live site anyway.
